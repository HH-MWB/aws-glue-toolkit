<h1 align="center">AWS Glue Toolkit</h1>

<p align="center">
  A streamlined CLI utility designed to simplify the AWS Glue development lifecycle.
</p>

## Quick Start

### Installation

```bash
pip install aws-glue-toolkit
```

### Basic Usage

```bash
# Build Glue artifacts (.dependencies.zip and .gluewheels.zip)
gtk build .

# Run job locally in container
gtk run .

# Run test suite
gtk test .
```

For source code, issue tracking, and contributions, visit the [GitHub repository](https://github.com/awesome-glue/aws-glue-toolkit).
